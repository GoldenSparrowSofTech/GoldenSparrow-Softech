## Brand & Style

This design system expresses high-tier executive prestige combined with hyper-modern computational authority. Crafted for an enterprise software and IT engineering consultancy, it balances sovereign corporate precision with visionary technological power. 

### Visual Movement: Neo-Corporate Cyber-Luxe
The aesthetic fuses deep space architectural dark mode with fine-metallurgy accents and cybernetic optical signals:
- **Foundations:** Layered obsidian strata, evoking pristine monolithic hardware enclosures and secure terminal architecture.
- **Metallics:** Radiant gold specular highlights, engineered gradient trims, and controlled auric luminosity signaling high-value execution and precision craft.
- **Accents:** Controlled atmospheric cyan pulses providing high-tech telemetry readouts, interactive data telemetry, and system observability cues.
- **Atmosphere:** Deep frosted glass elements, micro-hairline borders, ultra-crisp typography, and restrained ambient glows replacing traditional heavy drop shadows.

## Colors

The palette establishes an ultra-deep obsidian environment illuminated by precious-metal gold frequencies and diagnostic cyan glows.

### Palette Architecture
- **Primary Sovereign Gold (`#F59E0B`):** Reserved for core high-intent conversions, brand identity anchors, primary action states, and priority metrics. Extended via `#FBBF24` for metallic crest highlights, `#D97706` for deep edge contours, and `#FEF08A` for micro-specular light glints.
- **Secondary Cyber Cyan (`#06B6D4` / `#38BDF8`):** Reserved for technical readouts, operational telemetry, automated logic indicators, dynamic status beacons, and active system flow metrics.
- **Obsidian Neutrals:**
  - Base Void: `#090D16` (Deep canvas backing)
  - Surface Elevated: `#0D1322` (Card and panel backing)
  - Surface Highlight: `#141C33` (Hover fields, interactive cells, header docks)
  - Structural Border: `rgba(245, 158, 11, 0.15)` (Subtle gold boundary line) and `rgba(56, 189, 248, 0.12)` (System telemetry borders)
- **Text & Foreground Hierarchy:**
  - High Contrast Heading: `#F8FAFC`
  - Body Text: `#94A3B8`
  - Muted Technical Meta: `#64748B`
  - Gold Accent Text: `#FDE68A`

## Typography

Typography unifies structural engineering with executive confidence:
- **Headlines (`Space Grotesk`):** Provides a tech-forward, high-precision geometry. Use for all section banners, hero titles, stat counters, and modal headers.
- **Body & Controls (`Plus Jakarta Sans`):** Delivers clean readability, balanced apertures, and crisp rendering on dense OLED and high-DPI displays.
- **Technical Badges & Eyebrows (`label-caps`):** Rendered in uppercase with generous tracking (`0.12em`) to function as architectural stamps, telemetry keys, and security clearance tags.

## Layout & Spacing

The interface functions on a rigid, modular 12-column grid system calibrated to support complex enterprise portals, real-time dashboards, and client-facing architecture overviews.

### Breakpoints & Adaptive Rhythm
- **Desktop (1280px+):** 12-column grid, `margin: 3rem`, `gutter: 1.5rem`. Maximum content container width of 1440px centered.
- **Tablet (768px - 1279px):** 8-column grid, `margin: 2rem`, `gutter: 1.25rem`. Complex side-by-side matrices collapse to dual-column stacks.
- **Mobile (320px - 767px):** 4-column fluid layout, `margin: 1.25rem`, `gutter: 1rem`. Sticky top bar, bottom sheet navigation replacements, and single-column full-width module stack.

## Elevation & Depth

Visual hierarchy does not rely on muddy black shadows; it is established through layered obsidian luminance, optical glass refraction, and radial auric energy.

### Depth Hierarchy
- **Level 0 (Canvas Void):** `#090D16` static background with subtle radial gradients of `#06B6D4` (opacity 4%, blur 120px) in corners and `#F59E0B` (opacity 3%, blur 140px) at the top center.
- **Level 1 (Card Matrix):** Background `rgba(13, 19, 34, 0.72)` coupled with a 16px backdrop blur (`backdrop-filter: blur(16px)`). Bound by a 1px border gradient transitioning from `rgba(245, 158, 11, 0.25)` at the top edge to `rgba(20, 28, 51, 0.4)` at the bottom edge.
- **Level 2 (Active / Hover / Overlay):** Background `rgba(20, 28, 51, 0.88)` with backdrop blur (24px). Outer glow: `0 0 24px -4px rgba(245, 158, 11, 0.18)`.
- **Level 3 (Modals & Executive Flyouts):** Solid dark obsidian `#0D1322` wrapped with a hairline dual-tone stroke: `1px solid rgba(245, 158, 11, 0.35)` and an ambient shadow of `0 24px 48px -12px rgba(0, 0, 0, 0.75), 0 0 32px 0 rgba(6, 182, 212, 0.10)`.

## Shapes

The design system maintains a crisp, architectural shape language (Soft, level `1`). Micro-radii communicate solid-state industrial hardware, avoiding toy-like pill forms while maintaining comfortable visual ergonomics:
- **Base Components (Inputs, Buttons, Badges):** `0.25rem` (4px).
- **Cards & Data Modules (`rounded-lg`):** `0.5rem` (8px).
- **Executive Modals & Dialogs (`rounded-xl`):** `0.75rem` (12px).
- **Pill Exceptions:** High-precision telemetry tags and live status micro-pills use full circular caps (`9999px`) strictly for scalar badges under 24px height.

## Components

### Buttons
- **Primary Executive:** Gradient fill `linear-gradient(135deg, #FBBF24 0%, #F59E0B 50%, #D97706 100%)`, text `#090D16` bold, border `1px solid #FEF08A`, inner micro-bevel highlight, subtle auric shadow `0 4px 16px rgba(245, 158, 11, 0.3)`. Hover elevates glow intensity.
- **Secondary Cyber-Glass:** Background `rgba(13, 19, 34, 0.6)`, text `#F8FAFC`, border `1px solid rgba(6, 182, 212, 0.4)`. Hover transitions border to `#38BDF8` and applies `0 0 12px rgba(56, 189, 248, 0.25)`.
- **Tertiary Ghost:** Transparent background, text `#94A3B8`, border none. Hover shifts text color to `#FDE68A`.

### Status Badges & Chips
- **Gold Sovereign Badge:** Background `rgba(245, 158, 11, 0.08)`, border `1px solid rgba(245, 158, 11, 0.3)`, text `#FDE68A`, typography `label-caps`.
- **Cyber System Chip:** Background `rgba(6, 182, 212, 0.08)`, border `1px solid rgba(6, 182, 212, 0.3)`, text `#38BDF8`, typography `label-caps`. Includes a 6px pulsing center dot indicating real-time operation.

### Cards & Modules
- **Enterprise Spec Card:** Frosted dark `#0D1322` body, 1px perimeter border with directional light (top-left gold stroke blending into bottom obsidian), padding `space-lg`.
- **Feature Display Card:** Integrated top accent hair-line (`height: 2px`) featuring a gradient spanning `#F59E0B` to `#06B6D4`.

### Form Controls & Inputs
- **Text Inputs:** Background `rgba(9, 13, 22, 0.8)`, border `1px solid rgba(148, 163, 184, 0.2)`, text `#F8FAFC`, placeholder `#64748B`, height 44px, padding horizontal `space-md`. Focus state shifts border to `1px solid #06B6D4` with focus ring `0 0 0 1px #06B6D4, 0 0 12px rgba(6, 182, 212, 0.2)`.
- **Checkboxes & Radios:** Solid `#090D16` base, `1px solid rgba(245, 158, 11, 0.4)`. Checked state displays solid `#F59E0B` with deep charcoal obsidian glyph.

### Enterprise Additions
- **KPI Metric Display:** Top-line micro-label in `label-caps`, primary counter in `headline-lg` (`Space Grotesk`) in `#F8FAFC`, paired with an inline micro-trend badge reflecting secondary cyan or gold upward progression.
- **Glass Terminal Window:** Embedded code or pipeline inspector with `#090D16` solid substrate, thin header strip housing obsidian control nodes, and text output using technical monospace aligned with the system's geometric ethos.
